# YouTrube 4.0

Обновлён существующий `index.html`. Сборка, npm, серверная база и внешние API не нужны. Для обновления замените прежний файл, сохранив адрес сайта: данные привязаны к браузеру и адресу. При переносе на другой адрес используйте «Настройки → Экспорт / Импорт».

Добавлены сообщество с текстом, изображениями и опросами; уведомления о достижениях; демография и тепловая карта Studio; обсуждения видео и Shorts; заявки на подтверждение канала.

В редакторе видео появилось необязательное поле «О чём это видео / Что происходит в видео». Укажите конкретные факты и события. Локальный генератор использует ограниченные языковые шаблоны с цитатами этих фактов; полноценного понимания видео он не имитирует. При недостатке сведений остаётся только числовой счётчик комментариев. Видимые сообщения входят в агрегированный счётчик, ответы автора учитываются отдельно.

Демография записывается вместе с новыми просмотрами. Старым просмотрам не назначается выдуманная демография. Аналитика различает просмотры и уникальных зрителей. Реальные даты, пауза, ускорение статистики и единый офлайн-движок сохранены.

Подтверждение доступно после 100 000 подписчиков и заполнения профиля. Проверка занимает 10 реальных минут, сохраняется при закрытии страницы и не влияет на продвижение. Изменение названия требует новой заявки; изменение handle сохраняет подтверждение.

Пределы хранения: 80 своих постов, по одной стартовой тематической публикации для ограниченного числа NPC-каналов, до 12 видимых виртуальных комментариев на ролик, до 12 ответов в одной ветке и 60 уведомлений. Голоса агрегируются, отдельные записи для каждого виртуального зрителя не создаются. Изображения постов сохраняются в существующем IndexedDB и включаются в резервную копию.

Автоматические проверки запускаются без пакетов:

```sh
node tests-v4.cjs
node tests-v4-assets.cjs
node tests-v3.cjs
TZ=Europe/Moscow node tests-calendar.cjs
TZ=America/New_York node tests-calendar.cjs
TZ=Asia/Kathmandu node tests-calendar.cjs
```

Итоговые результаты: `test-results-v4.json`. Скриншоты показывают отдельную тестовую студию, а не данные основного канала. Завершение десятиминутной проверки проверялось с управляемыми часами в тестах и с просроченной тестовой заявкой в браузере.
